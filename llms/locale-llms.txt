# Locale

> Locale is a no-code workflow automation platform for operations, data, and engineering teams. Its visual builder chains apps and actions — HTTP, AI Actions, Run Code, Email, Slack, PostgreSQL, Sendgrid, and Fireflies.ai — with flow controls (conditional branching, delay, list iterator) to build, debug, and publish automated internal workflows. Backed by a16z. Locale publishes no first-party public REST API or OpenAPI at this time; this file is generated by the API Evangelist enrichment pipeline from Locale's public documentation surface.
